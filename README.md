# TrackField

Web/Android integration: [developer handoff](docs/ANDROID-HANDOFF.md), [API endpoints](docs/API-ENDPOINTS.md), and [Postman collection](docs/trackfield.postman_collection.json).

Monorepo scaffold for TrackField.

Structure:

- apps/web — Next.js frontend
- apps/api — Express backend
- packages/shared — shared constants and utilities

Run locally:

1. Install dependencies in repo root (use npm, pnpm or yarn)

```bash
npm install
```

2. Start dev: (requires installing per-app deps)

```bash
npm run dev
```
